# Parth Mudgal — Portfolio

Personal portfolio site for Parth Mudgal: full-stack developer and AI/ML enthusiast (B.Tech CSE AIDS, VIPS-TC).

## Stack

- React (Vite)
- HTML / CSS / JavaScript

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Content notes

Site copy is drawn from the resume only. Social / project URLs and certifications were not included because they were not provided—add them in `src/data.js` when available.
